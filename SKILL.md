# Infinity Manta Design

Lee `CLAUDE.md` y `DESIGN.md` completos antes de actuar. Para ideas, campañas o guiones, lee también `content/README.md`, `content/CONTENT_STRATEGY.md` y `content/FUNNEL.md`.

Para carruseles, sigue `social/CAROUSELS.md`. Para reels, sigue `social/REELS.md`. En ambos casos aplica `social/MEDIA_POLICY.md`, `social/COPY_GUIDE.md` y `social/EXPORT_CHECKLIST.md`.

Usa los recursos locales de `assets/`; no inventes recursos de marca. Todo carrusel usa únicamente el estilo Póster Editorial (`social/STYLE_POSTER_EDITORIAL.md`); su referencia es `entregas/calidad-precio/`. Cada historia tiene su propio ritmo dentro de ese sistema. `assets/references/carousel-approved/` es histórico y no se usa como referencia.

Para reels con modelo o voz en off, usa `content/VIRAL_HOOKS.md`, `content/AI_VISUAL_HOOKS.md`, `content/REEL_FORMULAS.md`, `content/SCRIPT_TEMPLATE.md`, `content/PRODUCTION_BRIEF.md` y `content/CTA_LIBRARY.md` antes de aplicar la dirección visual.
