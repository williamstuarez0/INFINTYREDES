# Banco fotográfico

Fotografías reales organizadas por el nombre original del servicio o producto. Antes de usarlas, abrirlas y comprobar que el contenido coincide con el mensaje.

Categorías disponibles:

- arenados;
- artículos promocionales;
- brand wall;
- exhibidores y habladores QR;
- letreros corpóreos y logos 3D;
- menús;
- microperforado y viniles;
- neón;
- papelería;
- reconocimientos;
- rotulaciones;
- señalética;
- stickers.

Los nombres ayudan a buscar, pero no autorizan a convertir un proyecto real en ejemplo negativo. Aplicar siempre `social/MEDIA_POLICY.md`.
