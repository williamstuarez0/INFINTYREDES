# Checklist final de exportación

## Contenido

- [ ] El hook se entiende en menos de un segundo.
- [ ] Cada cuadro tiene una sola idea principal.
- [ ] El copy no contiene datos inventados ni errores ortográficos.
- [ ] El CTA y el contacto son correctos.

## Marca

- [ ] Se usa un SVG real de `assets/brand/`.
- [ ] El logo tiene contraste y espacio libre.
- [ ] Poppins es la única familia tipográfica.
- [ ] La paleta coincide con `tokens/colors.css`.

## Visual

- [ ] Fotografías nítidas, con recortes intencionales.
- [ ] Ningún cliente real aparece como ejemplo negativo.
- [ ] No hay placeholders ocultos como si fueran finales.
- [ ] Textos y elementos respetan las zonas seguras.
- [ ] No hay desbordes, controles, guías, reglas ni UI del editor.

## Archivo

- [ ] Carrusel: cada slide mide 1080 × 1350 px.
- [ ] Carrusel: archivos separados y ordenados; PDF realmente multipágina si se entrega.
- [ ] Reel: 1080 × 1920 px; portada comprobada en recortes 4:5 y 1:1.
- [ ] Los nombres de archivo son claros y correlativos.
- [ ] Se revisó la exportación final, no solo la vista del editor.
