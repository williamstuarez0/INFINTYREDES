# Cómo usar este sistema en Claude Design

## Preparación

1. Sube este proyecto como Design System.
2. Para crear un carrusel nuevo, selecciona el Design System y elige **Blank**.
3. No elijas Slides: suele imponer lógica de presentación y puede alterar la proporción o la exportación.
4. Pega el prompt del encargo.
5. Si Claude informa que falta una imagen, añade el recurso o acepta un placeholder; no le pidas que improvise una pieza final con formas planas.

## Prompt base

> Crea la propuesta final de esta pieza usando el Infinity Manta Design System adjunto. Lee primero CLAUDE.md, DESIGN.md y los archivos del canal correspondiente. Usa los logos, fuentes, fotografías y referencias del repositorio. No presentes una propuesta previa ni detengas el trabajo para pedir aprobación, salvo que falte información esencial. Verifica visualmente la exportación final según social/EXPORT_CHECKLIST.md.

Después añade tema, objetivo, audiencia, estructura/copy, CTA y recursos concretos.

## Qué revisar antes de aceptar

- ¿Se siente como contenido de Instagram y no como diapositivas corporativas?
- ¿Hay fotografía real o un placeholder explícito donde falta?
- ¿El logo incluye el símbolo infinito y es un archivo SVG real?
- ¿Los slides tienen ritmo y no repiten la misma plantilla?
- ¿Los PNG son individuales y miden 1080 × 1350?
