# Prompt para actualizar el sistema en Claude

Actualiza el Design System que acabas de crear. No lo reconstruyas desde cero.

Se añadió una nueva carpeta `content/` dentro de este proyecto. Lee completos todos sus archivos y vuelve a leer `CLAUDE.md`, `README.md` y `SKILL.md`, que también fueron actualizados.

Integra al sistema una sección llamada **Content System** que explique y permita aplicar:

- estrategia de contenido;
- TOFU, MOFU y BOFU;
- pilares editoriales;
- banco de ganchos para reels;
- fórmulas narrativas;
- guiones para modelo o voz en off;
- brief de grabación y B-roll;
- biblioteca de CTA;
- mapa de las siete campañas iniciales.

Mantén intactas las secciones visuales, los tokens, logos, fotografías y reglas sociales ya creadas. El Content System define qué decir y con qué intención; el Design System define cómo debe verse y moverse.

No prometas viralidad. Presenta los ganchos como herramientas para mejorar retención, claridad y compartibilidad. Incluye al menos un ejemplo completo de reel con modelo que conecte hook, problema, demostración, solución, CTA y dirección visual de Infinity.

Al terminar, confirma qué archivos de `content/` utilizaste y qué nueva sección incorporaste.
