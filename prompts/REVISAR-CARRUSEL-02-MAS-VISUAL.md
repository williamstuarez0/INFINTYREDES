# Revisión del carrusel 02 — dirección más visual

Conserva el copy, la identidad, el formato 1080 × 1350 y la estructura de ocho slides, pero crea una segunda versión con una dirección mucho más fotográfica y narrativa, cercana al nivel visual del carrusel aprobado de visibilidad de marca.

La versión actual es clara y ordenada, pero los slides 02, 03, 04 y 07 se sienten demasiado infográficos. No quiero una presentación educativa basada principalmente en diagramas, tarjetas o bloques de texto. Quiero que la imagen demuestre la idea antes de que el usuario lea la explicación.

## Nueva dirección por slide

1. **Hook:** conservar el concepto de una calle/fachada, pero usar una escena generada de alto impacto que haga evidente que el letrero desaparece desde la distancia.
2. **Distancia:** reemplazar el diagrama por una escena fotográfica genérica vista desde tres distancias o por una composición fotográfica secuencial. El mismo letrero debe perder legibilidad al alejarse.
3. **Contraste:** reemplazar los cuadrados planos por una fachada genérica donde el letrero de bajo contraste casi desaparece, acompañada por una comparación visual secundaria con contraste correcto.
4. **Ubicación:** usar una escena fotográfica genérica en la que árbol, toldo o ángulo de circulación obstruyan naturalmente el letrero. Las líneas técnicas pueden señalar el problema, pero la fotografía debe dominar.
5. **Iluminación:** mantener enfoque fotográfico, pero mostrar claramente día frente a noche o apagado frente a iluminado. No usar una marca identificable como caso negativo.
6. **Coherencia:** usar fotografías reales positivas de Infinity y una composición editorial más grande; reducir las miniaturas y hacer que materiales, color y aplicación cuenten la historia.
7. **Checklist:** mantenerlo guardable, pero integrar una fotografía o detalle material de fondo/lateral para que no rompa el ritmo visual. La lista debe seguir siendo perfectamente legible.
8. **Evidencia + CTA:** conservar la fotografía real, pero revisar que el cierre tenga el mismo impacto editorial del slide 1.

## Imágenes generadas

Puedes usar varias imágenes generadas con Magnific u otra herramienta en los slides 1–5, porque representan errores genéricos y evitan señalar proyectos reales. Cada imagen debe demostrar un error diferente y mantener continuidad de luz, realismo y dirección de arte.

No incluir palabras, logos, rótulos ni marcas legibles dentro de las imágenes. El copy y el logo se añaden después en el diseño.

Si no puedes generar esas imágenes, entrega un prompt independiente y preciso para cada slide, conserva un placeholder fotográfico explícito y no lo reemplaces con diagramas planos como resultado final.

Los slides 6 y 8 deben usar material real de Infinity como solución y evidencia. El slide 7 puede combinar fotografía real con checklist.

## Ritmo

La secuencia debe sentirse así:

**impacto visual → demostración → demostración → demostración → demostración → solución real → herramienta guardable → evidencia y CTA**

No modifiques el Design System. Crea una nueva versión del carrusel y conserva la versión actual como referencia.
