# Hooks visuales con imágenes generadas

## Función

Una imagen generada puede ser el recurso principal del hook cuando una escena conceptual, exagerada o imposible de fotografiar comunica el problema más rápido que una fotografía convencional.

Puede producirse con Magnific u otra herramienta de imagen, siempre que el resultado mantenga calidad fotográfica y relación directa con el mensaje.

## Cuándo usarla

- Slide 1 de un carrusel para detener el scroll.
- Primer fotograma o portada de un reel.
- Metáfora visual de un problema abstracto.
- Comparación conceptual que no atribuya un error a un cliente real.
- Escena genérica que no existe en el banco fotográfico.

## Cuándo no usarla

- Como evidencia de un proyecto realizado por Infinity.
- Para inventar clientes, locales, testimonios o resultados.
- Cuando una fotografía real demuestra mejor el proceso o el acabado.
- Solo por ser llamativa si no explica el tema.
- Como relleno repetitivo en todos los cuadros. Una pieza educativa puede usar varias escenas generadas si cada una demuestra una idea distinta y la secuencia vuelve a evidencia real.

## Fórmula recomendada

1. **Hook generado:** imagen sorprendente y conceptualmente clara.
2. **Problema demostrado:** una o varias escenas generadas/neutras, cada una con una función distinta.
3. **Solución:** criterios prácticos apoyados por fotografía, detalle o composición editorial.
4. **Evidencia real:** fotografías o video auténtico de Infinity.
5. **CTA:** acción específica.

## Cantidad

- No existe un límite rígido de una imagen generada por pieza.
- Un carrusel educativo de ocho slides puede usar entre 2 y 5 escenas generadas cuando el tema necesita visualizar errores sin señalar clientes reales.
- Cada escena debe aportar información nueva; no repetir el mismo recurso con cambios mínimos.
- La solución, el portafolio y el cierre deben recuperar material real de Infinity para sostener credibilidad.

## Dirección para generar

- Crear la escena sin palabras, rótulos, logotipos ni marcas legibles.
- Dejar espacio negativo suficiente para el titular, pero añadir el texto después en el diseño.
- Pedir una sola idea visual, silueta clara y contraste fuerte.
- Usar perspectiva, escala, gesto, objeto inesperado o transformación para detener el scroll.
- Mantener materiales, sombras e iluminación plausibles, incluso cuando la idea sea surrealista.
- Evitar el aspecto genérico de stock, manos deformes, objetos duplicados y detalles físicamente imposibles no intencionales.
- Los colores de Infinity pueden aparecer como acentos; no es obligatorio teñir toda la imagen de azul y verde.

## Prueba de calidad

- ¿La imagen se entiende en menos de un segundo sin el copy?
- ¿Representa el problema o solo produce sorpresa?
- ¿El titular completa la idea en vez de repetirla?
- ¿Se distingue de una pieza genérica de inteligencia artificial?
- ¿Queda claro después que la evidencia real pertenece a Infinity?

## Responsabilidad de Claude

Si la herramienta no puede generar la imagen, debe entregar:

1. un prompt listo para Magnific o el generador disponible;
2. proporción y encuadre;
3. espacio reservado para copy;
4. lista de elementos que deben evitarse;
5. placeholder `HOOK VISUAL PENDIENTE` dentro del diseño.

Nunca sustituir la imagen pendiente con figuras planas presentadas como resultado final.
