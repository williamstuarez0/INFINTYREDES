# Fórmulas de reel

## A. Problema → prueba → solución

Ideal para TOFU/MOFU, 15–25 segundos.

1. 0–2 s: hook visual.
2. 2–6 s: nombrar el problema.
3. 6–12 s: demostrarlo con una prueba simple.
4. 12–19 s: explicar la solución.
5. 19–25 s: CTA.

## B. Antes → proceso → después

Ideal para MOFU/BOFU, 12–20 segundos.

1. Resultado final durante medio segundo.
2. Estado inicial.
3. Tres momentos del proceso.
4. Revelación del resultado.
5. Qué decisión hizo posible el cambio.
6. CTA.

## C. Tres errores

Ideal para TOFU, 18–30 segundos.

1. Promesa: “Tres errores que...”
2. Error 1 demostrado.
3. Error 2 demostrado.
4. Error 3 demostrado.
5. Resumen guardable.
6. CTA de guardado o consulta.

## D. Comparación

Ideal para MOFU, 20–35 segundos.

1. Presentar dos opciones.
2. Condición donde funciona A.
3. Condición donde funciona B.
4. Error de elegir solo por apariencia/precio.
5. Recomendación según contexto.

## E. Modelo + B-roll

Ideal cuando habla una persona en cámara.

1. Modelo en primer plano entrega el hook.
2. B-roll muestra el problema mientras continúa la voz.
3. Modelo vuelve para la idea principal.
4. B-roll demuestra solución/proceso.
5. Modelo cierra con CTA.

No mantener el mismo plano hablado durante todo el reel. Cambiar el estímulo visual cuando cambia la idea.

## F. Respuesta a pregunta

Ideal para MOFU/BOFU.

1. Mostrar la pregunta real en pantalla.
2. Respuesta directa: sí/no/depende.
3. Explicar dos o tres criterios.
4. Dar una recomendación accionable.
5. Invitar a enviar el caso concreto.
