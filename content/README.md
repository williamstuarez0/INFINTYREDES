# Infinity Manta Content System

Sistema estratégico para decidir qué comunicar, a quién, con qué formato y con qué intención comercial. Complementa al Design System: este sistema define el contenido; el Design System define su apariencia.

## Orden de uso

1. Define el objetivo y la etapa del embudo con `FUNNEL.md`.
2. Escoge un territorio en `CONTENT_PILLARS.md`.
3. Selecciona un gancho de `VIRAL_HOOKS.md`.
4. Si el hook necesita una imagen generada, aplica `AI_VISUAL_HOOKS.md`.
5. Estructura la historia con `REEL_FORMULAS.md`.
6. Escribe el guion con `SCRIPT_TEMPLATE.md`.
7. Prepara la grabación con `PRODUCTION_BRIEF.md`.
8. Elige un solo CTA de `CTA_LIBRARY.md`.
9. Aplica la identidad visual del Infinity Manta Design System.

## Principio

No se promete viralidad. Se diseñan piezas con mayores probabilidades de retención, comprensión, utilidad, confianza y conversión.
