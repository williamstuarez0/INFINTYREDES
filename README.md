# Infinity Manta Design System v2

Sistema visual operativo para crear contenido de Infinity Diseño y Publicidad sin perder la identidad de marca.

## Antes de diseñar

1. Lee `CLAUDE.md`.
2. Lee `DESIGN.md`.
3. Para estrategia, ideas y guiones, empieza en `content/README.md`.
4. Para carruseles, lee `social/CAROUSELS.md`; para reels, `social/REELS.md`.
5. Usa los recursos de `assets/`. No redibujes el logotipo ni inventes fotografías de trabajos de Infinity.
6. Usa `assets/references/carousel-approved/` como piso de calidad, no como una plantilla rígida.

## Estructura

- `assets/brand/`: variantes SVG autorizadas del logotipo.
- `assets/fonts/`: familia Poppins.
- `assets/photography/`: banco de fotografías reales de Infinity.
- `assets/references/`: piezas aprobadas para calibrar la calidad.
- `assets/manual/`: manual de marca original.
- `tokens/`: colores, tipografía y reglas de composición.
- `content/`: estrategia, TOFU/MOFU/BOFU, pilares, hooks, fórmulas, guiones, producción y CTA.
- `social/`: reglas específicas de carruseles, reels, copy, medios y exportación.
- `templates/`: briefs editables; no son diseños automáticos.
- `preview.html`: vista rápida del sistema y de las referencias.

## Principio central

Infinity no es una marca “dark UI”. Su lenguaje combina fotografía real, tipografía editorial grande, superficies claras y oscuras, contraste fuerte y acentos azul–verde. El producto terminado y el proceso de fabricación son protagonistas.

El Content System define qué decir y con qué intención; el Design System define cómo debe verse y moverse. Ambos deben utilizarse juntos.
